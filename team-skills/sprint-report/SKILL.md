# Skill: sprint-report

Создаёт или обновляет страницу текущего спринта под разводящей «Результаты спринтов» в Confluence: задачи из Jira с разбивкой по статусам, покрытие квартальных целей, нагрузка по исполнителям.

Дефолты (ID страниц, параметры спринта) — в [`defaults.yaml`](./defaults.yaml).
**Не правь дефолты в рантайме — только через PR.**

## Когда применять

Применяй для создания/обновления снимка спринта. Не применяй для:
- создания задач → `jira-planning-story`
- квартального планирования → `quarterly-planning`
- проставления лейблов спринта на задачи → делай вручную или попроси явно

## Что делать

### 1. Прочитай дефолты

Из `defaults.yaml`: `sprint_hub_page_id`, `quarterly_plan_page_id`, `reference_start`, `cadence_weeks`.

### 2. Вычисли метку текущего спринта

```
days        = (today − reference_start).days        # отрицательно, если раньше якоря
sprint_idx  = floor(days / (cadence_weeks × 7))
sprint_start= reference_start + sprint_idx × cadence_weeks × 7 дней
label       = "sprint-{sprint_start.year}-w{sprint_start.isoweek:02d}"
period      = "{sprint_start} — {sprint_start + 13 дней}"
```

Пример: today=2026-06-04, ref=2026-06-08, cadence=2 → idx=−1 → start=2026-05-25 (w21) → `sprint-2026-w21`.
Но если пользователь явно назвал другой спринт — используй его.

### 3. Вытащи данные параллельно

Запусти одновременно:
- **Задачи спринта:** `jira_search(jql='project = {{TRACKER_PROJECT}} AND labels = "{label}" ORDER BY priority DESC', fields=[key, summary, status, assignee, priority], limit=50)`
- **Квартальный план:** `confluence_get_page(page_id=quarterly_plan_page_id)`

### 4. Сопоставь задачи с квартальными целями

Из тела квартального плана извлеки пары «эпик → подзадачи»:
- Ищи секции вида «Эпик: {{TRACKER_PROJECT}}-NNNN» и «{{TRACKER_PROJECT}}-XXXX —» под ними.
- Для каждой задачи спринта проверь, есть ли её ключ среди подзадач.
- Есть → пиши «[Цель N: название|{{TRACKER_URL}}/browse/{{TRACKER_PROJECT}}-NNNN]».
- Нет → пиши «—».

Если задача тематически близка к цели, но явно не в подзадачах — отметь «(тематически)» и уточни у пользователя после создания страницы.

### 5. Создай новую страницу спринта

Всегда создавай новую страницу через `confluence_create_page(space="{{WIKI_SPACE}}", parent_id=sprint_hub_page_id, title="{label} · {период}")`.
**Никогда не обновляй существующую страницу спринта** — каждый вызов скилла создаёт свежий снапшот.

### 6. Отрендери страницу спринта

```wiki
*Период:* {start_date} — {end_date}
*Задач в спринте:* {total}
*Дата снимка:* {today}

JQL: {noformat}project = {{TRACKER_PROJECT}} AND labels = "{label}" ORDER BY updated DESC{noformat}

h1. В работе ({count})

|| Задача || Краткое название || Исполнитель || Приоритет || Квартальная цель ||
| [{{TRACKER_PROJECT}}-XXX|url] | название | Фамилия Имя | High/Medium/Low/Lowest | [Цель N: ...|epic_url] или — |

h1. Покрытие квартальных целей

|| Квартальная цель || Задач в спринте ||
| [Цель 1: ...|epic_url] | N ({{TRACKER_PROJECT}}-XXX, {{TRACKER_PROJECT}}-YYY) |
| Вне квартальных целей | N |

h1. Закрыто по исполнителям

|| Исполнитель || Закрыто задач || Задачи ||
| Фамилия Имя | N | [{{TRACKER_PROJECT}}-XXX|url], [{{TRACKER_PROJECT}}-YYY|url] |
```

Сортировка в таблице задач: по приоритету (High → Lowest), внутри одного приоритета — по исполнителю.
Сортировка нагрузки и закрытия: по убыванию числа задач.

### 7. Обнови разводящую страницу

Перепиши таблицу спринтов в `sprint_hub_page_id` целиком (не append), добавив строку для нового спринта *сверху*:

```wiki
h1. Спринты

|| Спринт || Период || Задач взято || Завершено || Статус ||
| [sprint-YYYY-wWW|page_url] | DD MMM — DD MMM YYYY | N | N | В работе |
```

Статус: «В работе» пока спринт активен, «Завершён» после окончания.

## Закрытие спринта

Если пользователь говорит «закрой спринт» или «подведи итоги»:
1. Обнови снимок задач (статусы могут измениться).
2. Заполни колонку «Завершено» в разводящей: число задач в статусе «Завершена».
3. Смени статус в разводящей на «Завершён».
4. Сними `current_sprint` со всех задач, которые **не** переносятся: `jira_update_issue` с обновлённым списком лейблов (убрать `current_sprint`).

## Смена спринта

Если пользователь говорит «начни спринт sprint-2026-w26»:
1. Закрой текущий спринт (шаг выше).
2. Найди все задачи с `labels = "current_sprint"` — это перенесённые.
3. Добавь новый лейбл (например `sprint-2026-w26`) к каждой через `jira_update_issue`.
4. Создай страницу нового спринта.

## Контракт ответа

После завершения — 3–4 строки:
- Ссылка на страницу спринта и разводящую.
- «N задач в работе, M привязаны к квартальным целям, K вне целей».
- Если что-то требует уточнения (тематические привязки, непонятные задачи) — задай один вопрос.
