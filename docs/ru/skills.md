# Каталог скиллов

Скилл включается сам, когда просьба совпадает с его описанием. Явный вызов: в Claude Code — `/имя-скилла`, в
Codex — назвав скилл в тексте («используй request-triage»). Отключить ненужные — `skills.exclude` в конфиге; все командные
разом — `skills.team = false`.

## Дежурство и инциденты

| Скилл | Когда | Пример промпта |
|---|---|---|
| `request-triage` | Разбор обращения или алерта до причины, решения и документа в базе | `разбери алерт https://chat.example.com/team/pl/abc123` |
| `observability-triage` | Латентность, ошибки, насыщение по метрикам и логам | `почему вырос 5xx у gateway в prod с 14:00` |
| `kubernetes-runtime-triage` | Падают поды: рестарты, probes, pending, давление на ноде, PVC | `поды registry-core в CrashLoopBackOff, разберись` |
| `service-network-triage` | DNS, TLS, ingress, шлюз API, недоступность сервиса | `registry.example.com не открывается из кластера, почему` |
| `mattermost-alerts-digest` | Сводка алертов из канала Mattermost за окно: повторы, flapping, затяжные, шумные namespace | `дайджест по алерт-каналу за ночь` |
| `postmortem` | Страница разбора в вики, задача-трекер инцидента, action items | `оформи постмортем по INC-7` |
| `duty-notes` | Статья дежурства в вики по разобранному кейсу | `задокументируй кейс из этого треда <ссылка>` |

## Инфраструктура

| Скилл | Когда | Пример промпта |
|---|---|---|
| `terraform-terragrunt-review` | Изменения, plan, drift, обновление провайдеров и модулей | `OPS-1234 добавь bucket для логов в prod, покажи plan` |
| `helm-argocd-gitops` | Чарты, values, Argo CD Application, diff и history | `почему argocd app payments OutOfSync, покажи diff` |
| `gitlab-ci-review` | `.gitlab-ci.yml`, rules, runners, lint, риски пайплайна | `проверь пайплайн деплоя на риски` |
| `vault-ops` | Политики, auth, AppRole, KV metadata, access denied | `почему у approle payments нет доступа к kv/payments/prod` |
| `yandex-cloud-devops` | Yandex Cloud: IAM, Managed Kubernetes, VPC, registry, Lockbox (необязательный) | `какие SA в каталоге dev имеют editor` |
| `versioned-docs` | Документация конкретной версии библиотеки или инструмента (Context7) | `что поменялось в External Secrets 0.10 по ClusterSecretStore` |

## Планирование и отчёты

| Скилл | Когда | Пример промпта |
|---|---|---|
| `jira-planning-story` | Плановая задача по шаблону «Проблема → План → Требования → Критерии приёмки → Ссылки» | `заведи задачу в джире про перенос registry` |
| `jira-planning-epic` | Эпик с правильно связанными подзадачами (Epic Name, Epic Link) | `оформи эпик про отказ от старого кластера` |
| `quarterly-planning` | Цель квартала: страница в вики, затем эпик и подзадачи | `оформи цель на Q3` |
| `sprint-report` | Снимок спринта в вики | `сделай отчёт по спринту` |
| `contractor-report` | Разбор ежемесячного Excel-отчёта подрядчика о часах: сверка с Jira, аномалии, страница в вики | `разбери отчёт подрядчика за май` |
| `daily-report` | Дневной отчёт в базе знаний | ровно `Сформируй daily report` |

Командные скиллы (`team-skills/`) написаны для связки Jira + Confluence + Mattermost и работают через
`sre-toolbox`. Перед первым использованием заполните `defaults.yaml` скилла: ID страниц вики (`<ID …>`), ID полей
Jira (`customfield_<ID …>`), метки тем, каналы. Подставляемые значения (проект, пространство, исполнитель)
берутся из конфига harness при установке.

## Работа с самими агентами

| Скилл | Когда | Пример промпта |
|---|---|---|
| `handoff` | Журнал длинной задачи | `заведи handoff`, `обнови handoff`, `закрой задачу` |
| `kb-compile` | Свернуть свежие находки и журналы в хабы (раз в неделю) | `сделай kb-compile` / `/kb-compile` |
| `retro` | Ретро сессии: что улучшить в обвязке (только вручную) | `/retro` в конце большой задачи |
| `writing-for-agents` | Правка скиллов, AGENTS.md, CLAUDE.md | `добавь в AGENTS.md правило про …` |

## Встроенное в Claude Code

`/code-review` (поиск багов в diff), `/simplify` (чистка кода), `/security-review`, `/loop 10m <промпт>` (повтор по
таймеру), `/schedule` (облачный агент по расписанию). Это не часть harness, но хорошо с ним сочетается.

## Субагенты и профили

| Кто | Где | Что делает |
|---|---|---|
| `kb-scout` | Claude Code | Широкий поиск по базе, репозиториям, логам, метрикам; пишущие инструменты запрещены; возвращает сводку с путями. «через kb-scout найди …» |
| `kb_scout` | Codex | То же для Codex; правило — звать, когда контекст заполнен больше чем наполовину |
| профиль `task` | Codex | Оркестратор: план → `coder` реализует → `reviewer` независимо проверяет → доработка до приёмки |
| профиль `incident` | Codex | `incident_worker` собирает логи и метрики только на чтение, оркестратор делает выводы |

Модели в файлах агентов — примеры; поставьте те, что доступны вам.
